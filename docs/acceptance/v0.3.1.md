# 验收卡 · v0.3.1 UI/UX

**怎么玩**：解压 `builds/eins-v0.3.1-windows.zip`，双击 `eins.exe`。
1. 在标题画面停几秒，看菜单滑进来，鼠标在按钮上晃一晃。
2. 点「设置」看一眼，关掉；再点「开始作战」打一局（约 2 分钟）。
3. 打的时候：
   - 点一下场上的角色，看看信息卡。
   - 按一次空格，看看暂停菜单。

规则和之前一样。这次只看界面和操作顺不顺。

不开游戏也可以看图：
- `docs/acceptance/v0.3.1-title.jpg`：标题画面。
- `docs/acceptance/v0.3.1-overview.jpg`：六个界面，包括标题、开场、战斗、暂停、设置、结算。

美术评审（Gemini）给 v0.3.0 打 3 分（满分 5）：「已经不像程序员做的了」。它提了几条意见，v0.3.1 已经改掉：
- 底部卡片、提示卡、费用框换成和弹窗一样的黄铜角饰纸面板。
- 字号调大，快捷键改成小铜章。
- 主按钮改成金字。
- 开场副标题加了暗底。

## 判断题

1. 现在的标题画面让你想点「开始作战」吗？ **是 / 否**
2. 整体界面还「粗糙」吗？ **A 不粗糙了 / B 好多了，但还有几处粗糙（请写是哪里） / C 还是粗糙**
3. 战斗时左下角的提示卡（会随战况变化）对你有帮助吗？ **是 / 否**
4. 点击角色弹出的信息卡，撤退按钮好找吗？ **是 / 否**
5. 下一步先做哪个？
   **A 手感**：主动技能、受击反馈、占位音效
   **B 内容**：再加 2 关、2 名新角色、2 种新雾兽、关卡选择
   **C 剧情**：世界观、角色设定、关前关后的对话
   **D 继续打磨 UI/UX**（写下最想改的地方）
