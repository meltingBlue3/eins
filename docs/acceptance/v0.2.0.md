# 验收卡 · v0.2.0 画风样张

**怎么玩**：解压 `builds/eins-v0.2.0-windows.zip`，双击 `eins.exe`，点「开始作战」。
战斗中按 **V**，或点右上角的「画风」按钮，可以随时切换画风：A → B → C → 灰盒 → A……
规则和 v0.1 完全一样。这次只看画面。

不想开游戏的话，看这两张图也可以：
- `docs/acceptance/v0.2.0-styles.jpg`：同一时刻的战斗画面，分别用三套画风画出来。
- `docs/acceptance/v0.2.0-lineups.jpg`：每套画风的全部角色、敌人和道具。

| | 画风 | 一句话 |
|---|---|---|
| A | 晴港赛璐璐 | 粗描边、平涂，像手游立绘缩小版，最清楚 |
| B | 雾色水彩 | 手绘纸感，雾气最浓，但角色容易融进背景 |
| C | 像素点阵 | 复古 16 位风，最省后续美术量，但和高清地块混搭不统一 |

美术评审（Gemini）的意见：A 可读性最好，B 最有雾港氛围、但角色不够突出，C 像素和非像素素材混在一起。**它推荐 A。**

## 判断题

1. 选哪套画风作为正式画风？ **A / B / C**
2. 在你选的那套里，5 名守灯人看起来像同一支队伍、和雾兽同属一个世界吗？ **是 / 否**
3. 战斗打起来时（雾兽挤成一团），你能一眼分清我方和敌人吗？ **是 / 否**
4. 地面（石板）和高台（木栈道）分得清吗？知道近战放哪、远程放哪吗？ **是 / 否**
5. 有没有哪个角色或敌人你特别喜欢，或者特别不喜欢？（可选，写名字就行，比如「喜欢医师，不喜欢雾犬」）

## 回复格式

直接回复一行，例如：`A 是 是 否，喜欢术士，雾甲太丑`
