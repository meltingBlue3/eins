## 判断题

1. 标题画面让你想点「开始作战」吗？ **是 / 否**
2. 你上次担心角色融进背景。加了描边以后（我方是暖色灯光边，雾兽是深紫墨线），还会融吗？ **A 不会了 / B 好一些，还不够 / C 描边太突兀，破坏了水彩感**
3. 底部的纸质卡片和黄铜框，和水彩地图是一套风格吗？ **是 / 否**
4. 打起来的时候，箭矢、法球、斩击、治疗光点这些特效看得清、分得开吗？ **是 / 否**
5. 下一步先做哪个？
   **A 手感**：主动技能、受击反馈、占位音效
   **B 内容**：再加 2 关（比 1-1 难）、2 名新角色、2 种新雾兽、关卡选择
   **C 剧情**：世界观、角色设定、关前关后的对话
