# 验收卡 · v0.1.0 灰盒可玩

**怎么玩**：解压 `builds/eins-v0.1.0-windows.zip`，双击 `eins.exe`，点「开始作战」。打一局大约 2 分钟。
**这一版只看能不能玩、好不好懂。** 画面是临时方块和圆圈，先不评价美术。

## 判断题

1. 不看说明，你能把第一个角色放到地图上吗？ **是 / 否**
2. 玩完一局，你明白「地面放近战挡路、高台放远程」了吗？ **是 / 否**
3. 第一局的结果？ **A 三星 / B 赢了但不到三星 / C 输了**
   （A 表示第一关偏简单，作为教学关可以接受；C 表示太难。）
4. 打完以后，有没有想再来一把？ **是 / 否**
5. 下一步先做哪个？
   **A 手感**：技能、打击感、占位音效
   **B 美术**：用 ComfyUI 出 3 套画风样张给你选
   **C 内容**：更多关卡、角色、敌人
6. 要不要把项目备份到你的 GitHub 私有仓库？ **是 / 否**

可选：一句话吐槽。

## 回复格式

直接回复一行就行，例如：`是 是 B 是 A 是，雾犬跑得太快`
