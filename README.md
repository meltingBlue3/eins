# 雾港守灯人（工作标题）· eins

原创二次元风格塔防。浓雾里的雾兽沿航道涌向灯塔，你把守灯人部署在地面和高台上守住它。

当前版本 **v0.3.0 · UI/UX**：一关完整可玩，水彩画面，有标题菜单、设置、暂停菜单和关内提示。

## 试玩

解压 `builds/eins-v0.3.0-windows.zip`，双击 `eins.exe`。不需要安装任何东西。

| 操作 | 方式 |
|---|---|
| 部署 | 点击卡片后点击发光格子，或者直接把卡片拖过去；数字键 1–5 选卡 |
| 撤退 | 点击场上角色 → 信息卡上的「撤退」（返还一半费用） |
| 暂停菜单 / 倍速 | 空格 / F，或右上角按钮 |
| 取消 / 关闭菜单 | 右键或 Esc |
| 设置 | 标题菜单或右上角齿轮：全屏、画面（水彩 / 灰盒）、伤害数字 |
